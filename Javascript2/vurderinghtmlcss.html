Git Field Manual

A simple reference for everyday Git commands.

Get started

git --versionCheck Git version.

git config --global user.name "Name"Set your username.

git config --global user.email "you@example.com"Set your email.

git clone <url>Copy a repository.

git initCreate a repository.

Inspect changes

git statusSee current changes.

git diffView unstaged changes.

git diff --stagedView staged changes.

git log --onelineView commit history.

git remote -vList remote repositories.

Save your work

git add <file>Stage one file.

git add .Stage changes in the current directory.

git add -pChoose changes to stage.

git commit -m "Message"Create a commit.

git restore <file>Discard unstaged changes to a file.

Work with remotes

git pullDownload and integrate changes.

git pushUpload your commits.

git fetchDownload remote updates.

git remote add origin <url>Add a remote repository.

git push -u origin mainPush main and set upstream.

Branch out

git branchList local branches.

git switch -c <name>Create and switch to a branch.

git switch mainSwitch to main.

git merge <branch>Merge another branch.

git branch -d <name>Delete a merged branch.

Recover and revise

git restore --staged <file>Unstage a file.

git commit --amendEdit the last commit.

git stashTemporarily save working changes.

git stash popRestore stashed changes.

git revert <hash>Reverse a commit safely with a new commit.

Advanced moves

git cherry-pick <hash>Apply a specific commit.

git rebase mainReapply commits on top of main.

git reflogView recent HEAD movements.

git blame <file>See who changed each line.

git bisect startStart searching for a bug.

Useful extras

git show <hash>Inspect a commit.

git branch -aList all branches.

git rm --cached <file>Untrack a file but keep it locally.

git help <command>Read command help.

Careful: Some commands can discard changes or rewrite history. Check your status before running unfamiliar commands.
